Fancy Text Universe 🌌

Fancy Text Universe is a powerful, single-file web application that transforms standard text into over 2,000 unique Unicode styles, emoji mixes, and aesthetic variations. It features a built-in AI suite powered by Google Gemini to perform advanced text operations like grammar fixing, slang translation, and roasting.

✨ Key Features

1. The Text Engine (2000+ Styles)

The core engine combines 40+ base Unicode maps (Serif, Script, Fraktur, etc.) with:

Emoji Mixers: Interleaves text with 50+ emoji patterns (e.g., "H🔥e🔥l🔥l🔥o").

Glitch & Cursed Text: Applies combinatorial diacritics (Zalgo text) for chaotic effects.

Aesthetics: Spaced text, decorations, and wrappers.

Infinite Scroll: Efficiently handles thousands of combinations without lagging the browser.

2. AI Magic Studio (15 Tools) 🤖

Integrated directly into the UI (no external icon fonts required), utilizing the Google Gemini API:

✨ Emojify: Adds relevant emojis to text contextually.

✍️ Grammar Fix: Corrects spelling and punctuation.

🧢 Gen Z Slang: Translates normal text into modern internet slang.

👔 Professional: Rewrites text for business/LinkedIn context.

🔥 Roast Mode: Aggressively mocks the input text.

💻 ASCII Art: Generates copy-pasteable text art.

👨‍💻 HTML Code: Converts text to valid HTML tags.

Plus: Hashtags, UwU Converter, Sarcastic, Poetic, Medieval, Pirate, Alien, and TL;DR.
